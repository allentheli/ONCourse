# Bundled fonts

All fonts are served from this folder so the site makes no third-party requests.
Each is licensed under the SIL Open Font License 1.1 (OFL), which permits bundling
and redistribution; the OFL text is available at https://openfontlicense.org.

- Atkinson Hyperlegible (Braille Institute) — builder and public pages
- Source Serif 4 (Adobe) — headings on the handout and site
- Source Sans 3 (Adobe) — handout body and timeline labels

Files are the "latin" subsets packaged by Fontsource (fontsource.org).
